# Data

By default the project trains on a **synthetic** dataset generated by `src/data.py` (no download needed).

To use a real dataset (e.g. Home Credit Default Risk or German Credit), download it, check its licence,
map it to the columns below, save as `data/raw/credit.csv`, and run:

    python -m src.train --data-path data/raw/credit.csv

Required columns: age, income, loan_amount, employment_years, credit_history_length,
num_open_accounts, num_late_payments, debt_to_income, home_ownership, default (0/1).
Optional (fairness audit only, never used as features): gender.

Do not commit raw data.
